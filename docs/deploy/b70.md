# Haven on the B70 machine (hackathon deployment)

Ticket 13. Spec: `docs/specs/haven-copilot-mvp.md` §7, §8.4, §16, ADR-006, ADR-009.
Status: **commands written, not yet run on the machine.** The recorded results go in
`docs/deploy/b70-<layout>-<time>.md`, written by `scripts/b70-deploy.sh` on the machine.

## What runs where

| Service | Model | Port (127.0.0.1 only) | Card, dual layout | Card, single layout |
|---|---|---|---|---|
| Note model | `Qwen/Qwen3-32B-AWQ` as `qwen3-32b-awq` | 8000 | 0, util 0.9, `--max-model-len 32768 --kv-cache-dtype fp8` | 0, util 0.5 (0.8 without Qwen3-ASR) |
| Whisper | `openai/whisper-large-v3-turbo` as `whisper` | 8001 | 1, util 0.12, `--max-model-len 448` | 0, util 0.12 |
| Qwen3-ASR (`HAVEN_ASR_REFINE`) | `Qwen/Qwen3-ASR-1.7B` as `qwen3-asr` | 8002 | 1, util 0.3, `--max-model-len 8192` | 0, util 0.15 |
| Haven | – | 8765 | – | – |

All three model servers use `vllm/vllm-openai-xpu:v0.26.0` through `scripts/b70-vllm.sh`
(`--dtype=bfloat16 --enforce-eager --async-scheduling --block-size 64`, `OFFLINE=1 PRIVILEGED=0`).
The deploy script records the image digest, so the next run can pin it.

## 1. Get the code onto the machine

Outbound port 22 is blocked on the machine; GitHub SSH works through port 443:

```bash
# ~/.ssh/config on the B70
Host github.com
  HostName ssh.github.com
  Port 443
  User git
```

```bash
cd ~/haven-copilot && git fetch origin && git checkout <branch> && git pull
```

## 2. Start the model servers and record the deployment

```bash
bash scripts/b70-deploy.sh                    # dual card: Qwen on card 0, Whisper + Qwen3-ASR on card 1
```

It writes `docs/deploy/b70-dual-<time>.md` (driver packages, kernel module, `xpu-smi discovery`,
image digest, one request to each server, card memory, container command lines, decision).
First start on a fresh machine: `OFFLINE=0` (downloads into `~/hf`).

**Fallback** if the dual layout does not come up:

```bash
docker rm -f vllm-haven vllm-asr vllm-qwen3-asr
LAYOUT=single bash scripts/b70-deploy.sh                       # all three on card 0
SKIP_QASR=1 QWEN_UTIL=0.8 LAYOUT=single bash scripts/b70-deploy.sh   # the verified 2026-11-17 setting, no Qwen3-ASR
```

Without Qwen3-ASR, start Haven without `HAVEN_ASR_REFINE` (Whisper text only).

## 3. Start Haven

```bash
HAVEN_LLM=openai HAVEN_LLM_URL=http://127.0.0.1:8000 HAVEN_MODEL=qwen3-32b-awq \
HAVEN_ASR=openai HAVEN_ASR_URL=http://127.0.0.1:8001 HAVEN_ASR_MODEL=whisper \
HAVEN_ASR_REFINE=1 \
python3 -m haven
```

Haven binds 127.0.0.1:8765 (no LAN mode). Accounts on: create two therapists and one admin
with `python3 scripts/add_user.py` before the demo (authorization demo, spec §16).

## 4. Reach it from a laptop (SSH tunnel)

```bash
ssh -L 8765:127.0.0.1:8765 <user>@<b70-host>
```

Then open `http://localhost:8765` in Chrome. `localhost` is a secure context, so the microphone
works without a certificate. When the machine is only reachable through JupyterLab, use the
tunnel method the platform offers (for example its port-forwarding / proxy for 8765) and say in
the results which one was used.
